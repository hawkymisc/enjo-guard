炎上ガード for X

投稿前に炎上リスクを判定する Chrome 拡張機能

X（旧 Twitter）で投稿ボタンを押した瞬間、下書きの炎上リスクを AI が判定します。 設定した閾値を超えたときだけ「このまま投稿しますか？」と確認し、閾値以下なら何も出ず、そのまま投稿されます。

判定する内容

  • 想定される批判の規模（0〜4 の 5 段階）
  • 特定の個人・団体への攻撃
  • 属性にもとづく差別的表現
  • 同意のない個人情報・私的なやり取りの公開
  • 裏付けのない断定
  • 皮肉や冗談が文字どおり受け取られる恐れ

投稿をブロックはしません

判定は確率であって正解ではありません。ダイアログには「書き直す」と「それでも投稿する」の両方があり、 最終的に決めるのは利用者自身です。判定できなかったとき（通信失敗・キー未設定など）も投稿は妨げず、理由を画面に表示します。

API キーは自分で用意します（BYOK）

typesafe.ai で取得したキーを設定画面に入力して使います。キーは端末内（chrome.storage.local）にのみ保存され、 開発者が利用者のデータや API キーを受け取ることはありません。
