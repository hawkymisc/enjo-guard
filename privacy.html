炎上ガード for X — プライバシーポリシー

最終更新: 2026-09-20

  • この拡張機能の開発者は、利用者のデータを一切受け取りません。
  • 投稿の下書き本文は、利用者自身の API キーで TypeSafe（api.typesafe.ai）にのみ送信されます。
  • API キーと設定は、利用者の端末内（chrome.storage.local）にだけ保存されます。
  • 解析ツール、広告、トラッキングの類は一切組み込んでいません。

取り扱う情報

1. 投稿の下書き本文

X（x.com / twitter.com）で投稿ボタンを押した時点の下書き本文を、炎上リスクの判定のために https://api.typesafe.ai/v1/systemone へ送信します。

  • 送信は判定のためだけに行われ、判定結果を表示した後は破棄されます。
  • 拡張機能側に保存されることはありません。
  • 送信先での取り扱いは TypeSafe のポリシーに従います。利用者自身の API キーによる利用であり、開発者は関与しません。

2. 返信先の投稿本文（既定では送信しません）

返信を書く場合、判定の精度を上げるために返信先の本文も送ることができますが、 この機能は既定で無効です。設定画面で明示的に有効にした場合にのみ送信されます。 利用者本人が書いた文章ではないため、本人の選択なしには外部へ出しません。

3. TypeSafe の API キー

  • chrome.storage.local に保存します。chrome.storage.sync は使いません（他の端末に同期されません）。
  • 判定リクエストの Authorization ヘッダとして api.typesafe.ai にのみ送られます。
  • 開発者を含む第三者に送信されることはありません。

4. 設定値

判定の閾値、モデル名、有効・無効の状態を端末内に保存します。端末外には出ません。

送信しないもの

  • 氏名、メールアドレス、アカウント名などの個人を特定できる情報
  • 閲覧履歴、クリック履歴、滞在時間などの行動データ
  • X のログイン情報、Cookie、認証トークン
  • 下書き以外のページ内容（タイムラインに流れている他者の投稿など）

第三者への提供

開発者は利用者のデータを受け取らないため、第三者に提供することもありません。 api.typesafe.ai への送信は、利用者自身が用意した API キーによる、 利用者と TypeSafe の間の通信です。

データの削除

拡張機能を削除すると、保存された API キーと設定も同時に削除されます。 設定画面で API キーを空にして保存することでも消去できます。

権限を求める理由

権限理由
storageAPI キーと閾値設定を端末内に保存するため
api.typesafe.ai炎上リスクの判定を依頼するため
x.com / twitter.com投稿ボタンの押下を検知し、判定結果のダイアログを表示するため

拡張機能は外部から取得したコードを実行しません（リモートコードの使用なし）。
